Pathway Database Analysis - Instructions

Pathway-oriented over-representation using KEGG, BioCyc, MetaCyc, or a user-supplied TERM2GENE mapping, opened from the integrated functional-analysis workspace.

Purpose

Use this module after you have a biologically selected gene list and a defensible tested-gene background. It asks whether the selected genes occur in pathway sets more often than expected from the genes that could actually have been detected and tested.

This is a pathway over-representation workflow. It does not replace differential expression and it does not infer that a pathway is activated merely because it is enriched.

Required inputs

  • Selected gene list: TSV, TXT, CSV, or XLSX containing the genes to test.
  • Tested-gene universe: all tested and mappable genes from the upstream experiment. Do not use only the significant genes as the universe.
  • At least one mapping source: online KEGG by itself is sufficient; alternatively import custom TERM2GENE, BioCyc, or MetaCyc data.
  • Results folder: a writable destination.

The gene column can be specified when the identifier column is not the first column.

You do not need to find or create a TERM2GENE file when using online KEGG. Choose a searchable KEGG organism, or type its code, scientific name, T number, or NCBI taxonomy ID. Click Validate / resolve, then confirm online use. The software downloads pathway-gene links and pathway names, caches them, and records provenance.

Recommended workflow

  1. Complete differential expression or another justified gene-selection analysis.
  2. Click Scan DE / functional results folder and select the completed Differential Expression or Functional Enrichment result tree. The recursive scan assigns the selected-gene table, complete tested-gene universe, compatible local mappings, and a default output location.
  3. If you want to enter data yourself, click Manual Excel input, paste into the in-application spreadsheet, consult its pale example placeholders, and choose Use data. Exporting an Excel workbook is optional.
  4. Review the selected genes and universe and verify that their identifiers match the planned database.
  5. For the easiest route, leave all local mapping boxes blank, choose the organism in Online KEGG organism, click Validate / resolve, and check the usage confirmation.
  6. For local curated data, import one or more TERM2GENE/BioCyc/MetaCyc tables instead of or in addition to KEGG.
  7. Run pathway enrichment and inspect annotation coverage, pathway membership, adjusted significance, and provenance together. Environment checks, database-library access, retrieval messages, and full errors appear in the live console.

Outputs

The main workbook is Pathway enrichment.xlsx. It records enrichment results, gene-pathway mapping, database summaries and provenance. Pathway enrichment interactive.html provides linked bar, dot, RichFactor, term-overlap and gene–pathway views; clicking a biological mark opens its contributing genes in the spreadsheet. Cached/retrieved mappings and the run log are kept under Intermediate files.

Interpretation and common problems

  • A br… value was entered: this is a KEGG BRITE/table identifier rather than an organism code. Choose the species from the dropdown. For Amycolatopsis orientalis, use aori.
  • Several KEGG organisms match: use the exact KEGG organism code reported by the error. Strain-level selection matters for bacteria.
  • Very few mapped genes: identifier systems probably differ between the input and pathway mapping. KEGG organism-specific links commonly use locus tags; review the mapping sheet before interpreting a negative result.
  • Inflated enrichment: check that the universe is all tested/mappable genes rather than all genes in a database or only DEGs.
  • No significant pathways: this can be a valid result; also check mapping coverage and selected-list size.
  • KEGG retrieval fails: verify internet access and the live-retrieval confirmation. The catalog loader uses KEGG's documented genome list and falls back to the special organism list. A successful retrieval is cached.
  • BioCyc/MetaCyc file unavailable: access and redistribution depend on the database terms. Obtain an authorized export, or use online KEGG/custom TERM2GENE instead.
