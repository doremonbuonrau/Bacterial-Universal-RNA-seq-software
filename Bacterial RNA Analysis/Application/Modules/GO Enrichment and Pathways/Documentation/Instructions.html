Functional enrichment and co-expression networks

One coordinated bacterial workflow from shared inputs and annotation to one workbook and one interactive report.

Purpose

Interpret differential expression and discover co-expression modules, hubs, traits, and candidate regulatory relationships in the same run. Annotation and gene identifiers are prepared once and reused by both analysis stages.

Start with one input action

In section 1, choose Use latest DE analysis results, Scan DE / functional folder, or Manual Excel input. These actions fill the differential-expression result, normalized expression matrix, sample metadata, optional regulator list, offline gene-to-term mapping, optional universe, and result location whenever available. Manual Excel input opens the in-application grid with pale examples already visible in empty cells. Type or paste real values over them and choose Use data; the examples are not data. Optional Excel export contains only the editable input sheets and no separate example sheets.

The differential-expression result is required for enrichment. The normalized expression matrix and sample metadata are required for co-expression because correlations must be calculated across samples and cannot be reconstructed from a differential-expression result table. Manual Browse controls remain in section 1 as fallbacks for files that cannot be assigned automatically.

Configure the workflow from top to bottom

  1. One scan and shared inputs supplies the coordinated analyses in a compact two-column layout.
  2. Gene-to-term mapping details defaults to online annotation and can be switched to an offline mapping file. Type an exact organism name or taxonomy ID, or use the adjacent search button.
  3. Functional enrichment in the left section 3 selects clusterProfiler ORA, fgsea, or topGO. topGO defaults to All (BP + MF + CC); tick Show gene selection and gene-set settings on this same panel only when the defaults need changing.
  4. Co-expression and network method in the right section 4 lets users choose CEMiTool, WGCNA, or GENIE3. Its automatic-module control and Show module, edge, and regulatory settings checkbox share one compact row.
  5. The action row enables online KEGG and STRING settings and then runs GO enrichment, co-expression, pathway enrichment, and PPI in one coordinated job. Their completed tables and interactive plots are merged into one workbook and one report.

One annotation pass

Offline mode reuses the same supplied gene-to-term mapping for enrichment and module-level interpretation. Online mode reconnects gene IDs to retained RNA-processing aliases, queries the selected UniProtKB source, and uses retained protein or CDS sequence with DIAMOND when required. The generated gene annotations and GO mapping are written once, then supplied to both enrichment and network analysis.

Analysis methods

Functional enrichment

  • clusterProfiler ORA tests a thresholded gene list.
  • fgsea uses the complete signed ranking.
  • topGO performs GO graph-aware analysis.

Co-expression and networks

  • CEMiTool automatically detects co-expression modules.
  • WGCNA supports signed or unsigned weighted networks and soft-power selection.
  • GENIE3 infers directed regulator-to-target relationships when a regulator list is supplied.
Sample size: At least 20 independent samples are recommended for co-expression. Below 15 samples, exploratory mode is selected automatically and results are labelled as hypothesis-generating.

Parameter guide and package options

Parameter guide explains input relationships, enrichment thresholds, gene-set sizes, transformations, sample-size requirements, module settings, and edge limits together. Guided package options lists documented functions for the selected enrichment method and the guided CEMiTool workflow in one dialog. Checked overrides are stored in the same configuration and exact effective calls remain in the run log.

One environment and one run

Check environment validates one Conda environment containing annotation, clusterProfiler, fgsea, topGO, CEMiTool, plotting, Excel, and HTML-report dependencies. No second network installation is required.

Run combined analysis performs the stages in order: shared annotation, functional enrichment, CEMiTool co-expression inference, all plots, combined Excel organization, then the combined offline interactive report. The two progress indicators and live console follow this complete sequence. If a required stage fails, the coordinated job stops and reports the exact stage instead of silently creating a partial success.

One functional-analysis workspace

The selected parent location receives one Functional enrichment and co-expression analysis folder. Its root contains Functional enrichment and co-expression results.xlsx and Functional enrichment and co-expression interactive.html. The HTML uses one Analysis / visualization selector for every enrichment and co-expression plot, with linked result sheets, appearance controls, full hover text, module renaming, and export tools. The same application workspace opens pathway-database enrichment and STRING PPI; each produces its own auditable Excel workbook and linked self-contained interactive HTML report. Figures are grouped together and essential handoff, configuration, progress, and provenance files remain under Intermediate files.

Recommended path: Run Differential Expression first, open this combined module, click Use latest DE analysis results, review sections 2 through 5, and click Run combined analysis once.
