Differential Expression

Count-based statistical comparison of replicated bacterial RNA-seq conditions.

Purpose

Compare replicated bacterial RNA-seq conditions using raw integer gene counts and sample metadata.

Engines

  • edgeR quasi-likelihood is the recommended production default.
  • DESeq2 provides a widely used shrinkage-based workflow.
  • limma-voom is useful for multifactor designs and many contrasts.

Guided package options

Select an engine and choose Guided package options... to browse documented DESeq2, edgeR, or limma-voom arguments. Check Use, then set Boolean values with checkboxes, fixed choices with drop-downs, and numeric or list values with validated fields. The dialog explains each option, identifies protected workflow arguments, opens bundled offline package manuals, validates the installed package version at runtime, and records every effective function call and override. Unlisted free-form arguments are intentionally not exposed. The bundled offline package manual opens without an Internet connection.

Inputs

Raw integer count matrix, sample metadata, result folder, and optional bacterial gene coordinates. To enable the IGV track, the coordinate table must contain gene_id, seqid, start, and end; start and end are 1-based inclusive and gene IDs must match the count matrix.

Outputs and plots

The selected parent location receives a named engine analysis folder. Its root contains one verified Excel workbook with the complete DE table, significant genes, normalized and filtered counts, plot matrix, metadata, advanced diagnostic/comparison tables, and the IGV audit when available. The unified offline interactive HTML report is stored beside the workbook, while its purpose-built plots are grouped under Figures; bedGraph tracks and technical files are grouped separately. The DE root additionally contains four dedicated downstream-input folders for GO Enrichment and Pathways, Co-expression and Networks, Pathway Database Analysis, and STRING Protein Associations. These folders copy the appropriate DE table, tested-gene universe or selected-gene list, and normalized expression/metadata where applicable. GO and Co-expression/Networks also receive recovered RNA-processing reference support so their online annotation does not have to search backward through the project whenever those files are available. The persistent log records the configuration, exact commands, package information, source hashes, and complete line-numbered R, Python, and shell source used by the run.

Every successful run adds the canonical MA plot, sample expression distributions, correlation and hierarchical clustering, interactive 3D PCA, source-of-variation, raw p-value, gene-rank, selected-gene heatmap, and single-gene expression analyses. Two or more contrasts additionally produce an UpSet analysis, a Venn view for two or three contrasts, and pairwise fold-change comparison. Three or more condition levels additionally produce fuzzy expression-pattern clusters with membership strengths. When a batch is modeled, before/after visualization diagnostics are added without replacing the count-based DE model. Gene-bearing plots and the complete annotated spreadsheet are linked in both directions: a plot mark selects its full row, while spreadsheet selection focuses MA/rank positions, replaces the single-gene explorer, or chooses heatmap rows.

When gene coordinates are supplied, every run also writes an IGV bedGraph using 0-based half-open coordinates and signed log2 fold change, so positive bars are upregulated and negative bars are downregulated; significance remains in the workbook and technical audit table.

Choose the linked-result-table option to drag result variables into plotting roles and create the configurable Volcano, Circos, genome region, scatter, combined violin + box, or histogram plots. Duplicate fixed Volcano and circular-genome views are not generated. Scatter can optionally encode an additional variable by point size, so a separate bubble mode is unnecessary. The visualization controls are plot-aware, and the single-gene point color uses the shared specialized primary-color control. Fold change can be displayed as raw ratio, log2, log10, or natural log. Select Typography… to choose among 10 common fonts, set text size and color, and apply bold, italic, or underline styling to graph text. Export TIFF, JPEG, PNG, SVG, PDF, or interactive HTML at a selected paper size and resolution.

Combined handoff: Functional Enrichment and Co-expression Networks scans this DE result once. The same action loads the complete DE table, normalized expression matrix, sample metadata, optional universe, and retained reference/identifier support for one coordinated functional-analysis run.
