# Differential Expression

This is an integrated analysis module in Bacterial RNA Analysis. It uses the shared R, Python, WSL2 environment, and plotting components stored under `Modules/Shared Downstream Components`, but it has its own independent GUI window, instructions, log, result controls, and navigation.

The selected parent output location receives an engine-named analysis folder containing one formatted Excel workbook, one unified offline interactive report, and grouped `Figures`, `BedGraph`, and `Intermediate files` folders when applicable. The report includes sample-distribution QC, correlation and hierarchical clustering, 2D/3D PCA, source-of-variation, p-value, gene-rank, top-variable-gene, and single-gene analyses. Multi-contrast runs add UpSet, a two-/three-contrast Venn view, and fold-change-comparison analyses; designs with at least three condition levels add fuzzy expression-pattern clusters. All source tables are workbook sheets, and gene-bearing plot marks link to the spreadsheet.

After workbook verification, the DE result root contains all handoff files needed by Functional Enrichment and Co-expression Networks, Pathway Database Analysis, and STRING Protein Associations. The combined functional-analysis GUI scans the DE result once and loads its enrichment table, normalized expression matrix, sample metadata, universe, and retained reference/identifier support together. The original compact handoff/provenance tables remain grouped under `Intermediate files`. When a 1-based inclusive gene-coordinate table is supplied, the module also exports a signed log2-fold-change bedGraph for IGV and includes its auditable mapping in the workbook.

Use **Guided package options...** to browse documented DESeq2, edgeR, or limma-voom arguments. Check **Use**, then set Boolean options with checkboxes, fixed choices with drop-downs, and numeric or list values with validated fields. Workflow-owned data, design, contrast, and completeness arguments are protected; every effective function call and override is retained in the persistent run log. Unlisted free-form arguments are intentionally not exposed; only documented guided options can be changed.
