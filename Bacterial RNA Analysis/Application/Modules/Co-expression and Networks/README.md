# Co-expression and Networks legacy entry

This launcher now opens the combined **Functional Enrichment and Co-expression Networks** workflow. Co-expression no longer requests a second input scan, output folder, environment check, or analysis run. Its required normalized expression matrix and sample metadata appear once in section 1 of the combined GUI.

The combined run prepares annotation once, executes enrichment and the selected CEMiTool, WGCNA, or GENIE3 method, and writes one workbook plus one interactive report containing both result modules.
