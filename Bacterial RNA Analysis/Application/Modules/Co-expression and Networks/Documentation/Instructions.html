Functional enrichment and co-expression networks

The former network entry now opens one coordinated functional-analysis workflow.

One shared start

Use Use latest DE analysis results, Scan DE / functional folder, or Manual Excel input in section 1. These actions fill the differential-expression result, normalized expression matrix, sample metadata, optional regulator list, gene-to-term mapping, optional universe, and result location whenever available. Manual Excel input opens the in-application grid with pale examples visible immediately in empty cells. Type or paste real values over them and choose Use data. Optional Excel export contains the editable input sheets only, with no separate example sheets. The normalized matrix and metadata remain necessary because correlations across samples cannot be reconstructed from a differential-expression summary.

One annotation and environment

Choose one offline mapping or one online annotation pass. The generated identifiers, functions, and GO links are reused for enrichment and network interpretation. Check environment and Install or update manage one shared environment containing all enrichment, co-expression, regulatory-network, plotting, Excel, and report dependencies.

Methods and settings

Section 3 on the left selects clusterProfiler ORA, fgsea, or topGO and keeps its optional gene-selection/gene-set controls behind one checkbox in that panel. Section 4 on the right selects CEMiTool, WGCNA, or GENIE3; automatic module detection and the optional module/edge/regulatory detail checkbox share one row. There is no separate numbered settings section. At least 20 independent samples are recommended, and below 15 the warning-labelled exploratory option is selected automatically. The same action row can enable online KEGG pathway enrichment and STRING PPI so all four analysis families run from the shared input and are merged into one workbook and interactive report.

One guide, run, and result

Parameter guide explains both analyses together. Guided package options exposes the documented functions for both selected methods in one dialog. Run combined analysis performs annotation once, enrichment, module/network inference, all figures, workbook organization, and report generation in that order.

The result is one Functional enrichment and co-expression analysis folder containing Functional enrichment and co-expression results.xlsx and Functional enrichment and co-expression interactive.html. The HTML has one unified Specialized analysis dropdown and one linked-sheet selector instead of separate Functional enrichment and Co-expression views. Appearance includes a Show biological data labels option for crowded specialized plots.

Recommended path: Run Differential Expression, open either the functional-enrichment or legacy co-expression entry, click Use latest DE analysis results, review sections 2 through 5, then run once.
