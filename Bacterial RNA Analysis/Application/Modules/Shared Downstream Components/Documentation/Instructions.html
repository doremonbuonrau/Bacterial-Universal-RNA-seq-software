Installation

Open either downstream workflow from the main Bacterial RNA Analysis page. In the shared status panel, select Install or update. One conda environment named prok-rnaseq-downstream supplies annotation, enrichment, co-expression/network inference, R, Python, Plotly, CairoSVG, Pillow, and Excel export; there is no separate GO or network environment.

The first installation requires Internet access and can take substantial time. The visualization studio runs only on 127.0.0.1, reads local result tables, and serves Plotly.js from the installed Python package. Result data are not uploaded to an external service.

Differential expression

Choose DESeq2, edgeR quasi-likelihood, or limma-voom. Provide a raw integer count matrix and sample metadata. Select the sample-ID column, condition column, optional batch column, reference level, and test level. Gene filtering starts at a minimum count of 10 in at least 3 samples; change this only when the study design justifies it.

Use Scan RNA Processing folder for a completed upstream result tree. To paste data yourself, click Manual Excel input. Pale italic examples appear immediately inside otherwise empty cells; type or paste over them, then choose Use data. The examples are display-only and are never submitted. Export workbook is optional and writes only the editable input sheets, without separate example sheets.

EngineBest use
edgeR quasi-likelihoodRecommended production default with TMM normalization, negative-binomial GLMs, and quasi-likelihood testing.
DESeq2Widely understood negative-binomial workflow with size-factor normalization and strong documentation.
limma-voomFast linear-model framework for multifactor, time-course, and many-contrast designs.
Raw counts only. The GUI and backend reject non-integer TPM, FPKM, CPM, and other normalized values. Every compared group must contain at least three biological replicates, and condition plus batch must form a full-rank design.

Differential-expression plots and IGV track

The interactive visualization studio supports volcano, MA, scatter, bubble, bar, combined violin + box, histogram, heatmap, and line plots. The analysis-time plotting engine also supports sample PCA, a top-gene heatmap, a Circos-style circular genome plot, and a selected-gene grouped bar view. Interactive HTML controls provide hover, zoom, pan, box selection, reset, and PNG export from a toolbar outside the plotting region. DE plots can display fold change as raw ratio, log2, log10, or natural log without changing the underlying statistical test.

IGV bedGraph

When a coordinate table is supplied, the DE run automatically writes differential_expression_log2fc.bedGraph. The input requires gene_id, seqid, start, and end with 1-based inclusive coordinates. The exporter converts them to bedGraph's 0-based half-open convention, sorts the intervals by sequence and position, and writes signed log2 fold change. Positive bars indicate higher expression in the test level; negative bars indicate lower expression. The coordinate sequence names must match the reference loaded in IGV.

Selected gene range

Enter row numbers such as 1 to 10 or exact gene identifiers. The generated grouped bar graph shows log2 normalized expression plus 1 for every sample or the mean of each condition. Condition means include replicate standard-deviation error bars. Views are limited to 100 consecutive genes for readability.

Circular and linear genome views

Genome views require real annotation coordinates. The studio reads gene_id, seqid, start, end, and strand from RNA-processing reference exports or the workbook IGV audit. Circos uses coordinate-width radial DE bars without endpoint bubbles and supports interactive zoom. Genome region uses filled directional gene arrows spanning the true gene interval, keeps the complete replicon available while panning, and links spreadsheet selection to the highlighted gene arrow.

Functional enrichment and co-expression

This is one coordinated workflow. In section 1, supply the DE result, normalized expression matrix, sample metadata, result folder, optional universe and regulator list; then choose offline or online gene-to-term mapping. Use latest DE analysis results loads the complete DE handoff, Scan DE / functional folder scans that result tree explicitly, and Manual Excel input opens the guided in-app data editor with empty cells and visible example placeholders. Section 3 configures enrichment and keeps optional gene-selection and gene-set-size controls behind its local checkbox. Section 4 exposes CEMiTool, WGCNA, and GENIE3 and keeps optional module, edge, and regulatory controls behind the checkbox beside automatic module detection. The action row optionally enables online KEGG and STRING, then Run all analyses executes the four result families from one input and merges them into one workbook and one interactive report.

MethodInput logic
clusterProfiler ORATests a thresholded upregulated, downregulated, or combined gene list against the tested gene universe.
fgseaTests all mapped genes using a signed ranking statistic, normally the DE test statistic.
topGOGO-only analysis that accounts for ontology graph structure. All (BP + MF + CC) is the default and runs the three ontology graphs before combining the results.

Online gene-to-term mapping is the default. Offline mapping accepts a long gene_id/term_id table or GMT. Online mapping provides common bacterial entries and an adjacent organism-search button; there is no placeholder organism choice. No organism / no taxonomy ID is allowed, but unrestricted matching is less certain and the software requests confirmation. Sequence-based annotation checkpoints UniProt functional records by accession; after a connection reset, rerunning resumes only missing records. Completed pathway and STRING tables and plots are incorporated directly into the combined output.

Co-expression and networks

MethodInterpretation
CEMiToolAutomated co-expression module detection and a good default for less experienced users.
WGCNAAdvanced weighted modules with automatic or manual soft-threshold power and module-trait correlations.
GENIE3Directed regulator-target predictions from expression and an optional regulator list.
Below 15 samples, exploratory mode is selected automatically and the output is labelled for cautious interpretation. At least 20 independent samples is preferable. Do not preselect only DEGs for an unsupervised co-expression network.

Input formats

Counts or expression

Delimited TSV, TXT, or CSV. The first column contains unique gene identifiers. Remaining columns are sample values. Differential expression requires raw integer counts. Network analysis requires library-size-normalized expression: keep log2(x + 1) selected for normalized counts or CPM, and clear it for VST, rlog, voom, z-scores, or another already-transformed matrix. Already-transformed matrices may contain negative values.

Metadata

One row per sample. Sample identifiers must exactly match matrix column names. Additional condition, batch, time, strain, or treatment columns can be used by the selected workflow.

Functional mapping

A long table with one gene-to-term pair per row, or a GMT file with one gene set per row.

Outputs

Differential expression creates its engine-named result folder. The combined functional workflow creates one Functional enrichment and co-expression analysis folder containing enrichment, module/network results, one verified Excel workbook, and one combined interactive HTML report. Automatic and user-exported plots are grouped under Figures, DE genome-browser tracks under IGV, and essential handoff plus complete code-bearing provenance files under Intermediate files. Redundant recognized TSV files are removed only after workbook verification; unknown user files are preserved.

Scientific limits

Differential expression estimates association with the design and does not prove causation. Enrichment depends on annotation completeness, identifier mapping, and the selected universe. Co-expression is undirected correlation. GENIE3 is directed prediction, not validated regulation. Interpret network evidence together with operons, transcription-factor knowledge, motifs, binding data, and experiments.

Interactive visualization studio

After a successful analysis, select Open interactive visualization studio. The local browser page lists available result tables and their columns. Drag variables into X, Y, value, color, size, and label roles. The preview updates immediately when the plot type or appearance changes.

Select Typography… under Appearance to control all graph text. Choose Arial, Times New Roman, Calibri, Segoe UI, Helvetica, Georgia, Verdana, Tahoma, Courier New, or Garamond; set a 6–72 px text size; use a theme-aware or custom color; and combine bold, italic, and underline styles. The dialog provides a live text sample, and Apply to graph updates the current preview and subsequent exports.

Export supports TIFF, JPEG, PNG, SVG, PDF, and self-contained interactive HTML. Paper presets include A0 through A5, Letter, Legal, and square, with portrait, landscape, and custom dimensions. Maximum safe resolution is the default; custom DPI from 72 to 1200 is available when the selected paper size remains within the export safety limit.
