Bacterial RNA Analysis 1.9.77

1. The differential-expression volcano scale now reserves enough right margin for every Up/Down tick label.
2. Genome region view no longer draws the redundant “Gene length and direction” label.
3. Custom primary, secondary and gradient-palette colors are now always active for specialized GO and co-expression plots; network groups and edges remain independently editable.

6. Detected module names are collected across all combined result sheets. Renaming fully replaces the generated module label (for example, “M1” becomes “123”, not “Module 123”) throughout plots, hover text, legends and linked spreadsheet values without changing source files.
7. Functional-enrichment Circos supports mouse-wheel zoom and true drag-to-pan movement while preserving hover and click alignment.
8. The linked GO/co-expression spreadsheet includes an Export Excel button that exports all currently filtered rows as an Excel-compatible workbook.
9. The cellular-component view uses the supplied anatomically positioned cell illustration recolored for the suite. Plain borderless labels are distributed around the cell, remain draggable, and keep their leader endpoints fixed to corrected anatomical targets. The confusing effect/count circles and their legend were removed.
10. The generated report and package identify this revision as version 1.9.77.
11. Every Plotly gradient/color bar now has an explicit whole-bar drag controller in differential-expression, GO, co-expression, generic, exported HTML, Cartesian and polar views, including trace types for which Plotly does not expose reliable native editing. Moving a bar safely reclaims the vacated right margin without collapsing the plotting domains; Reset restores its original position and margin.
12. Numeric-gradient plots reserve a protected right canvas margin, so their complete bars, tick labels and titles remain visible in embedded interactive reports. Numeric marker arrays also retain their gradient when custom colors are applied.
13. Genome region view places the fold-change title and available +/− strand labels in a protected far-left gutter while giving more width to the genomic plotting region.
14. The redundant explanatory sentence above the interactive GO/combined workspace has been removed.
15. The functional-analysis GUI again exposes CEMiTool, WGCNA and GENIE3 network-method selection together with sample ID, correlation, WGCNA type, soft power, maximum genes, log transform and automatic-module controls.
16. Moving a gradient bar away from the right edge now expands both the reserved margin and any colorbar-shortened Cartesian domain; Volcano and other numeric-gradient plots immediately use the released canvas width, while Reset restores the original layout.
17. topGO now defaults to All (BP + MF + CC), including the preview fallback when no explicit ontology choice has yet been made.
18. Gene-to-term mapping now defaults to online annotation; users can still switch to a local offline mapping file at any time.
19. The bacterial cellular-component map shows mapped-gene counts only as plain parenthetical text. Its former circle key, effect-size circles, and movable legend were removed; component labels retain explicit drag handling while leader endpoints stay attached to the correct anatomy.
20. Appearance controls now include live left, right, bottom, and top plot-margin sliders for making more or less room for long labels, titles, and legends in generic and specialized plots.
21. Functional-enrichment, combined GO/co-expression, and differential-expression interactive reports no longer reserve the empty status strip at the top; the analysis workspace grows into that recovered vertical space.
22. STRING PPI now validates the selected numeric taxonomy ID against the official STRING v12 organism catalog before retrieval. Unsupported organisms produce a specific, actionable message in the live console instead of only “backend exited with code 2”; no related species is substituted silently.
23. STRING PPI now provides an editable supported-organism dropdown, a Validate organism action, and a circular help control for the 0-1000 minimum-score range and its coverage-versus-confidence tradeoff. The redundant optional gene-column field and Back to network methods action were removed.

Scan dialogs and summaries repeat the selected scope.

Pathway Database Analysis, Transcript Discovery, and TU Architecture use the same integrated status/action/console design. Checks, progress, and full errors stream in place; the core installer opens its own console because it can require elevation and interactive prompts.
26. Pathway Database Analysis mapping controls use fixed, shorter labels and DPI-safe row spacing so TERM2GENE, BioCyc, MetaCyc, and online KEGG inputs remain separated instead of overlapping.
27. Differential Expression, Functional Enrichment and Co-expression, STRING PPI, Pathway Database Analysis, Transcript Discovery, and TU Architecture now include Manual Excel input. Each action opens the same in-application spreadsheet workflow, validates the current cells or an imported workbook, extracts analysis-ready files, assigns them to the GUI, and lets the user run normally; seven reusable schemas are bundled.
28. Scientific-module header actions now reserve separate positions for Instructions, Database library, intermediate-method navigation where applicable, and the single main-menu return. STRING PPI exposes only one Back action: Back to analysis modules.
29. Manual workbook imports accept custom expression/count sample-column names, validate matching metadata and numeric counts, and write only after all required-sheet checks succeed. Each GUI import uses a fresh folder and clears absent optional inputs so a previous workbook cannot contaminate a new analysis.
30. Gene lists auto-detect gene/protein/locus headers in single-column TSV/TXT as well as CSV and Excel; headerless lists retain their first gene. Scientific consoles drain both output streams while keeping input/navigation controls locked during runs. Measured headers and scroll-safe minimum page sizes prevent hidden buttons and collapsed consoles on short windows.

Empty My data cells show pale italic example placeholders that are never submitted as values; users can overwrite them by typing or pasting. Use data validates/assigns without creating an Excel file; Export workbook and Import workbook are optional. Separate example buttons are removed.
