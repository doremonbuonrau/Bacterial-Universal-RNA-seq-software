deepTools bamCoverage

Creates raw or CPM-normalized strand-aware BigWig/bedGraph coverage tracks.

Pipeline-managed and protected
BAM input, output file and format, bin size, threads, MAPQ, SAM flags, normalization, strand, exact scaling

Options exposed by Bacterial RNA Analysis

OptionFlag / settingDefaultChoicesMeaning
Smoothing window length--smoothLength1Average neighboring bins over this window; values not exceeding bin size have no effect.
Center reads/fragments--centerReadsFalseCenter each read or fragment before calculating coverage.
Ignore duplicate reads--ignoreDuplicatesFalseExclude reads with identical mapping positions according to deepTools rules.
Skip uncovered regions--skipNonCoveredRegionsFalseOmit zero-coverage regions instead of writing zero-valued bins.
Additional scale factor--scaleFactor1Multiply the pipeline-computed coverage values by this factor.
