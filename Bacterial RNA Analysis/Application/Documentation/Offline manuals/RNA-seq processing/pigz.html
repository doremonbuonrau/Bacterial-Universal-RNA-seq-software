pigz compression

Parallel gzip compression for generated FASTQ files.

Pipeline-managed and protected
stdin/stdout streams, thread count, compressed output path

Options exposed by Bacterial RNA Analysis

OptionFlag / settingDefaultChoicesMeaning
Compression levelSelected valuedefaultdefault, -1, -2, -3, -4, -5, -6, -7, -8, -91 is fastest/largest; 9 is slowest/smallest; default uses pigz's standard level.
Rsync-friendly blocks--rsyncableFalseReset compression blocks at input-dependent boundaries.
Independent compression blocks--independentFalseCompress blocks independently for damage isolation.
Do not store name/time--no-nameFalseOmit original filename and timestamp metadata.
