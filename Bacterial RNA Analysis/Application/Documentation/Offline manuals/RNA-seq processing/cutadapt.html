Cutadapt

Adapter trimming and read filtering for short reads.

Pipeline-managed and protected
adapter sequences, input/output FASTQ paths, core count, baseline quality and minimum length

Options exposed by Bacterial RNA Analysis

OptionFlag / settingDefaultChoicesMeaning
Trim terminal N bases--trim-nFalseRemove N bases from both ends of each read.
Discard reads without an adapter--discard-untrimmedFalseKeep only reads in which a configured adapter was found.
Disallow indels in adapter matching--no-indelsFalsePermit substitutions only when matching adapters.
Maximum adapter error rate--error-rate0.1Maximum error rate allowed in an adapter match.
Minimum adapter overlap--overlap3Minimum number of matching adapter bases.
Adapter-removal rounds--times1Repeat adapter removal this many times per read.
Maximum N content--max-n0.1Discard reads whose N content exceeds this fraction.
