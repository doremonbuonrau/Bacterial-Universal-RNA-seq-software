Dorado basecaller

Basecalls Oxford Nanopore POD5 input using the selected HAC or SUP model.

Pipeline-managed and protected
model, POD5 input, BAM output stream

Options exposed by Bacterial RNA Analysis

OptionFlag / settingDefaultChoicesMeaning
Compute device--deviceautoauto, cpu, cuda:all, cuda:0Select automatic, CPU, all NVIDIA GPUs, or the first NVIDIA GPU in the WSL/Linux runtime.
Inference batch size--batchsize00 leaves hardware-specific selection to Dorado; larger values use more accelerator memory.
Minimum mean Q score--min-qscore0Discard basecalls below this mean quality threshold.
Write move-table tags--emit-movesFalseStore the move table in mv tags for compatible downstream uses.
Scan POD5 folders recursively--recursiveFalseSearch subdirectories for POD5 files.
