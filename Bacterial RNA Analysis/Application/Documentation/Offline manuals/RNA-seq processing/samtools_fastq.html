SAMtools fastq

Converts supplied or Dorado-produced BAM data to FASTQ.

Pipeline-managed and protected
input BAM, stdout FASTQ stream, threads, compression pipe

Options exposed by Bacterial RNA Analysis

OptionFlag / settingDefaultChoicesMeaning
Use read names-nFalseUse the read name instead of adding /1 and /2 suffixes.
Always add /1 and /2-NFalseAlways append mate suffixes to read names.
Use OQ quality values-OFalseUse original qualities from the OQ tag when present.
Copy RG, BC and QT tags-tFalseAdd common read-group and barcode tags to FASTQ headers.
