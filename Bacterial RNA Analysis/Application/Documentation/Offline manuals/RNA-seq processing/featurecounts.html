featureCounts

Primary integer gene counting and strand-orientation auditing.

Pipeline-managed and protected
SAF annotation, BAM input, output table, threads, strand, MAPQ, primary alignments, paired/long-read mode

Options exposed by Bacterial RNA Analysis

OptionFlag / settingDefaultChoicesMeaning
Assign multi-overlap reads-OFalseAssign a read to every overlapping feature instead of treating it as ambiguous.
Count multi-mapping reads-MFalseInclude reads reported at multiple genomic locations.
Choose largest overlap--largestOverlapFalseAssign each read to the feature with the largest overlap.
Minimum overlapping bases--minOverlap1Minimum read bases that must overlap a feature.
Minimum read overlap fraction--fracOverlap0Minimum fraction of the read that must overlap a feature.
Ignore duplicate-marked reads--ignoreDupFalseExclude reads carrying the duplicate flag.
