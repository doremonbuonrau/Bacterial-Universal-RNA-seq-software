NanoPlot

Quality and length plots for long-read FASTQ data.

Pipeline-managed and protected
input FASTQ, output directory, threads, run prefix

Options exposed by Bacterial RNA Analysis

OptionFlag / settingDefaultChoicesMeaning
Distribution plot type--plotskdekde, dot, hexRendering method for bivariate distribution plots.
Show N50 mark--N50FalseAdd the read N50 value to length plots.
Log-transform read length--loglengthFalseUse a logarithmic read-length axis.
Downsample to N reads--downsample10000Use at most this many reads for plotting. Leave Use unchecked to disable explicit downsampling.
Static plot format--formatpngpng, jpg, svg, pdfFile format for static figures.
