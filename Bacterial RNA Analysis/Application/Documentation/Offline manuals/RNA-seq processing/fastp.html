fastp

Adapter, quality and length filtering for short reads.

Pipeline-managed and protected
input/output FASTQ paths, thread count, quality and minimum-length baseline, JSON/HTML reports

Options exposed by Bacterial RNA Analysis

OptionFlag / settingDefaultChoicesMeaning
Correct paired-end overlaps--correctionFalseCorrect mismatched bases in confidently overlapping read pairs.
Trim poly-G tails--trim_poly_gFalseEnable poly-G tail trimming.
Trim poly-X tails--trim_poly_xFalseEnable poly-X tail trimming.
Filter low-complexity reads--low_complexity_filterFalseDiscard reads below the selected sequence-complexity threshold.
Complexity threshold (%)--complexity_threshold30Minimum percentage of adjacent bases that differ when low-complexity filtering is enabled.
