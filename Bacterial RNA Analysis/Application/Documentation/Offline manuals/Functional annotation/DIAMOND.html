DIAMOND sequence annotation

DIAMOND performs high-speed protein sequence similarity searches. Bacterial RNA Analysis uses it to scan protein FASTA with blastp or CDS nucleotide FASTA with translated blastx against a locally cached reviewed UniProtKB/Swiss-Prot sequence database.

Shared Database Library: reusable UniProt FASTA files and DIAMOND indexes are stored under /root/.local/share/prok-rnaseq/Database Library/UniProt. Once a valid copy exists, later GO and Network analyses reuse it without another download unless Update/Refresh is selected or the cached file fails validation.

Workflow

StageBehavior
Database preparationThe reviewed Swiss-Prot FASTA is downloaded from UniProt only when the shared Database Library copy is absent or when refresh is requested, then converted to DIAMOND database format.
Protein FASTAUses DIAMOND blastp.
CDS nucleotide FASTAUses DIAMOND blastx to search translated nucleotide sequence against proteins.
Default acceptanceE-value at most 1e-5 and sequence identity at least 30%. The best retained hit is used for UniProt functional and GO annotation.

FASTA identifiers

The software first tries to reconcile FASTA identifiers to analysis gene_id values using retained RNA-processing aliases such as locus tags, original GFF IDs, gene names, old locus tags, and protein IDs. Exact header equality is therefore not required when the FASTA and downstream table originate from the same reference annotation. For gene/locus-tag online annotation, the retained reference genome and coordinates can also be used automatically for DIAMOND fallback when direct UniProt identifier matching is incomplete.
